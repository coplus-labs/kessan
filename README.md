# 動く決算報告資料（kessan）

決算書3期分の数字から、社長への決算報告で画面に映す「動く決算報告資料」（表紙＋7ページ）を描く表示プログラムです。
コプラス株式会社の「UPGEAR AI」で作った資料を表示するために使います。

## 使い方

HTMLに数字と文章を入れ、このファイルを読み込みます。

```html
<script>window.KESSAN={"data":{…},"text":{…}};</script>
<script src="https://cdn.jsdelivr.net/gh/coplus-labs/kessan@v1.0.0/kessan-v1.js"></script>
```

- 数字・グラフ・計算はすべて data から計算します
- 文章の中の数字は差し込み記号（例：`{売上_前期比}`）で書きます
- 資料の数字はHTMLの中だけにあり、このプログラムからどこかへ送ることはありません
- 表示にはインターネット接続が必要です（このファイルとWebフォントを読み込むため）
